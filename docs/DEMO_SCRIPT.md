# 1-Minute Demo Video Script

| Time | Screen | Say |
|---|---|---|
| 0:00–0:08 | Login page | "This is LearnSphere, a full-stack LMS built with React, Express, Firebase Auth and Supabase." |
| 0:08–0:15 | Click *Continue with Google*, then onboarding | "Users sign in securely with Google and choose to learn or to teach." |
| 0:15–0:28 | Instructor: My Courses → New course → add lessons and an assignment → Publish | "Instructors create courses, add video lessons and assignments, and publish them." |
| 0:28–0:42 | Student: Browse → Enroll → open lesson → Mark complete | "Students enroll, watch lessons and mark them complete. Progress updates live." |
| 0:42–0:50 | Student: submit assignment; Instructor: grade it | "Assignments are submitted and graded with feedback." |
| 0:50–0:57 | Student dashboard, then Admin panel | "Dashboards show progress, deadlines and grades. Admins manage users and roles." |
| 0:57–1:00 | Architecture slide / README | "Every API call is checked with Firebase tokens, and data lives in Supabase PostgreSQL." |

**Tip:** use two browsers (or one incognito window) signed in with two Google accounts, one instructor and one student.
